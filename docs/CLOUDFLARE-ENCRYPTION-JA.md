# 暗号化済み結果の保存準備

GitHubに公開されている `public-key.pem` は模擬テスト専用であり、**実データに使えません**。
Cloudflare Workerや公開リポジトリに秘密鍵・生の事業者一覧を置くことも禁止です。

`src/cloudflare-envelope-bridge.mjs` は、別途用意したRSA 3072ビット公開鍵について、
公開鍵の識別用SHA-256値を求め、既に暗号化された記録へ `keyId` を追加します。
これは暗号化済みデータの形式確認であり、秘密鍵による復号成功を保証するものではありません。

非公開の安全なLinux環境専用の `scripts/prepare-private-envelope.mjs` を用意しております。
入力済みの暗号化ファイル、公開鍵、出力先は、すべて公開GitHubリポジトリの外側に置きます。
GitHub Actions上とWindows上では処理を拒否し、出力ファイルは上書きせず権限を制限します。

現段階では、Cloudflare実環境にD1や認証情報を設定・反映しておりません。
生データ処理、暗号鍵の作成、実サイトへの通信は別途確認を要します。
