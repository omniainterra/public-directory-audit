# Cloudflare無料枠の確認用Worker

このアプリは実サイトを巡回しません。外部への通信、記録の読み込み、メール送信、フォーム送信、定期実行はすべて無効です。
公開できる唯一の応答は `GET /health` で、安全な検証用の固定情報だけを返します。

利用者はCloudflare Workers & Pagesで「アプリケーションを作成する」→「Worker」を選択してください。
料金プランを変更したり、GitHubを自動デプロイ接続したりしないでください。
Cloudflare上の実デプロイは、必ず別途承認を得てから行ってください。

このプロジェクトの従来のNode.js版調査コードは、そのままCloudflareへ移植できません。
実サイト調査には、robots・利用規約、アクセス制限、危険ドメイン対策、暗号化、CPU・外部呼び出し枠の確認が別途必要です。
非公開の顧客情報、既存監査記録、暗号鍵をこの公開リポジトリや公開Workerに投入しないでください。
