# Cloudflareの実サイト調査（未デプロイのオフライン検証）

src/cloudflare-research-probe.mjs は調査ロジックだけの技術試験でございます。
現在公開中の Worker からは呼び出されず、通信先も自動的には取得いたしません。

許可したホスト名、明示的に渡した読み取り専用通信関数がなければ動作しません。
HTTPSのみ、robots.txtが読めないときは停止、リダイレクト追従なし、最大３ページ、
応答本文の読み取り上限64KiB、GETのみ、フォーム・メール送信なしです。

本番適用前には、認証、厳密な回数制限、暗号化された非公開データ保管、
Cloudflare固有の通信安全性、商用用途の許容、10ミリ秒CPU枠を確認いたします。
CloudflareのfetchはNode.jsのDNS固定方式と同一ではありません。
本ソースを公開Workerのコード編集画面に貼り付けないでください。
