# 秘密情報をチャットに貼らないためのオフライン準備

`tools/offline-credential-creator.html` はHTMLファイル１つで動作する、鍵と認証トークンを端末内生成するための**未実行ツール**です。

重要：ウイルス・不審通信の警告があったWindows端末では、感染がないことを確実に確認するまで利用しないでください。別の信頼できる端末の利用を推奨します。

GitHub Actions上ではこのツールのコードと暗号機能を模擬検証するだけです。実運用向け鍵やトークンは、ユーザー本人が利用する信頼できる端末で生成し、秘密鍵ファイルを第三者へ送信しないでください。

HTMLを手元に保存し、ネット接続を切ってからブラウザーで開きます。外部ネットワーク利用とブラウザーストレージはCSPにより禁止しています。

生成される情報：
- 48バイトの安全な乱数に基づく認証トークン（本人だけが保管）
- そのトークンのSHA-256ハッシュ（Cloudflareの照合設定に使う）
- 独立したRSA-OAEP 3072ビット鍵ペア（公開鍵のみCloudflare側で暗号化に使用可能）
- 公開鍵のSPKI SHA-256識別値（Cloudflareの照合設定に使う）

秘密鍵そのもの、認証トークンそのもの、顧客データ、既存の米国事業者リストは公開リポジトリやCloudflareに貼り付けないでください。

このツールの動作は、Cloudflare Workersでの認証設定や営業先調査を自動的に開始するものではありません。
